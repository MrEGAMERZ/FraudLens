# Presentation Script: The Open-Source Agent Skill

**Context for the Speaker:** Use this script when you want to flex the technical depth of your project. This highlights that you didn't just build a standard web app, but actually contributed an open-source AI primitive for other developers.

***

### 🎤 The Professional Script

"While the web dashboard is great for everyday users, we wanted to ensure FraudLens could protect developers and power users exactly where they already work. 

That is why we didn't just build a web application—we built a modular, open-source security primitive. 

As part of this repository, we have authored and open-sourced a native **AI Agent Skill**—packaged as a standardized `SKILL.md` file. 

**Why is this a game-changer?** 
Modern developers are increasingly using AI coding assistants like Antigravity, Claude Code, and Cursor in their terminals. By simply copying our open-source `SKILL.md` file into their local `.agents/skills/` directory, any developer's AI assistant instantly 'learns' how to become a fraud detection expert. 

Without writing a single line of integration code, your local AI agent can now natively execute FraudLens. You can be in your terminal and simply ask your AI to *'scan this suspicious recruiter email'* or *'audit this job portal URL'*. The agent will read our skill instructions, run the Python CLI we built, evaluate the Fraud Funnel Compression Score, and return the threat analysis right inside your IDE.

We didn't just build a standalone product. We created an open-source, plug-and-play security layer that the entire open-source community can seamlessly integrate into their own AI workflows. This is the future of agentic security."

***

### 💡 Key Talking Points (Quick Reference)
- **Beyond the Browser:** Moving fraud protection from a website into the terminal/IDE.
- **The Format:** It’s packaged as a standard `SKILL.md` file, which is the universal instruction format for modern Agentic AI systems.
- **Zero-Friction Integration:** Developers just drop the folder into their workspace, and their AI instantly gains FraudLens capabilities.
- **Agentic Security:** We are pioneering a way for AI assistants to actively protect their human developers from social engineering and phishing.
